# data目录放置说明

本仓库保留当前`input/1021/1021_50cm`的左右原始示例图，以及model目录和数据放置说明；其他历史数据、模型权重与输出不上传。`.gitkeep`用于保留空目录。

## 首次复现

以下默认输入目录和两张1224×1024原图已随仓库提供。首次运行只需另行准备兼容的TorchScript模型；输出目录由程序自动创建：

```text
data/
├── input/
│   └── 1021/
│       └── 1021_50cm/
│           ├── left.png     左相机原始未校正图
│           └── right.png    右相机原始未校正图
├── model/
│   └── waft_B.pt            导出的TorchScript模型
└── output/
    └── 1021_50cm/          运行时自动生成
```

也可使用`left.jpg/right.jpg`或`.jpeg`；同名文件存在多个后缀时优先PNG。不要放入已经校正的图像再次执行校正。

模型下载和导出方法见[`model/README.md`](model/README.md)。当前C++程序不直接读取官方`.pth`。

## 更换自己的数据

1. 在`data/input`下建立自己的图片对目录，将图片命名为`left.png`、`right.png`。
2. 修改`src/main.cpp`的`input_folder`，使其指向该目录。
3. 使用与这套相机、1224×1024采集模式对应的标定。不能只将其他尺寸的旧图resize后套用本套标定。
4. 运行后结果保存到`data/output/<输入目录最后一级名称>/`；名称相同时覆盖同名结果文件。

## 输出内容

程序自动保存左右校正图、水平线预览、相对视差预览和模型辅助通道图；米制深度数组与深度预览位于输出的`depth`子目录。输出目录不需要提前放文件。

除当前1021_50cm示例外，其他历史日期输入目录和output系列目录已从仓库移除。不同日期、尺寸、模型的结果不要混用。

Git忽略规则会阻止这些目录中的实际数据被普通`git add`加入仓库；仅目录占位和README说明被跟踪。
